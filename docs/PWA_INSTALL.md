# RINGFALL install and offline behavior

RINGFALL is an installable browser game, served from the canonical HTTPS site. The web manifest supplies standalone display metadata, square 192/512 icons, a maskable icon and the RINGFALL app identity. The document adds an Apple touch icon and iOS web-app metadata. The install action appears on the initial screen and main menu.

On browsers exposing `beforeinstallprompt`, the action opens the browser's native install confirmation only after the player taps it. On iPhone and iPad it explains the Share → Add to Home Screen flow, because those browsers do not expose that Chromium prompt. Safari on macOS gets the Add to Dock steps; other browsers receive browser-menu guidance. The UI detects an already installed standalone launch and does not show a redundant install action.

The root service worker caches the app shell, manifest, install icons, and the built JavaScript/CSS referenced by the shell. It then caches same-origin game chunks and static game assets as they are requested, with an 80-entry runtime bound, a 96 MiB budget measured from the fetched bodies, and a 24 MiB per-response ceiling. Oversized files are left uncached. Old app-shell cache versions are removed on activation. API requests and Durable Object WebSocket traffic bypass Cache Storage. Offline navigation falls back to the cached app shell, then to a small offline explanation page. Any action depending on multiplayer or uncached media/data still needs a network connection. Players should open the game once while online before relying on the installed copy offline.

These files provide standards-based web installation and best-effort offline single-player resources. They do not create native App Store, Play Store, Microsoft Store, or Linux package releases. Browser installation UI varies by operating system, browser, managed-device policy and embedding context. HTTPS is required outside localhost. iOS/Android physical-device install and offline-launch acceptance remain device-level release checks; desktop Chromium installation can be exercised in browser automation.
