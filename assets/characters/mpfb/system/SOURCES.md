# MakeHuman system assets

Selected unmodified files from the official MakeHuman system asset pack:
https://static.makehumancommunity.org/assets/assetpacks/makehuman_system_assets.html

Archive: https://files.makehumancommunity.org/asset_packs/makehuman_system_assets/makehuman_system_assets_cc0.zip
Fetched September 12, 2026 using bounded HTTP byte ranges to extract selected ZIP entries.

Included: short01, short02 and long01 hair; young light-skinned male/female and middle-aged dark-skinned male skin materials. The source pack labels these with legacy phenotype names; those names are asset identifiers and do not infer any real wrestler's ethnicity.

The official pack is CC0. LICENSE.md records the MakeHuman source/assets license distinction. Source MHCLO and MHMAT files retain their author metadata. Baked textures are derived locally from these assets; source photos are not included in their license. Runtime hashes are in public/characters/materials.json.
